# Mazinga Micro Workers

Mazinga Micro Workers is a micro-task platform where workers can sign in
and complete distributed tasks. The system is designed using a
microservices architecture with scalability and asynchronous processing
in mind.

## Core features
- Worker registration and authentication
- Task discovery and completion
- Service-oriented and modular design
- Cloud-ready and container-friendly

## Architecture approach
- Spring Boot microservices
- Clean architecture principles
- Asynchronous and event-driven components (planned)

## Status
Actively evolving.
